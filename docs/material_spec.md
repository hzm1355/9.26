## Blender 材质命名建议

导入 FBX 后，建议将材质重命名为以下标准名称以便自动着色：

```
道路类：
- road_main, road_secondary, road_intersection

标线类：
- marking_white, marking_yellow, crosswalk, arrow

绿化类：
- grass, vegetation, tree

建筑类：
- building_main, building_roof, building_glass, building_wood

设施类：
- sign_warning, sign_prohibition, sign_info, light_pole

运动类：
- track, field_green, field_basketball

其他：
- sidewalk, curb, parking
```
