# 3D Web 可视化使用说明

## 快速开始

### Windows 用户

1. **双击运行** `start.bat`
   - 会自动检查并安装依赖
   - 服务器启动后，浏览器会自动打开

2. **或手动运行**：
   ```cmd
   cd v2x_traffic_sim\smart_car_gui\web_3d
   python server.py
   ```

### WSL/Linux 用户

```bash
cd v2x_traffic_sim/smart_car_gui/web_3d

# 安装依赖
pip3 install -r requirements.txt

# 启动服务器
python3 server.py
```

## 访问地址

服务器启动后，在浏览器打开：
- **HTTP**: http://localhost:8080
- **自定义端口**: `python server.py 9000` → http://localhost:9000

## 功能说明

- **3D 场景**: Three.js 渲染的仿真场景
- **车辆模型**: 5 辆智能小车（3 辆主车 + 2 辆 TurtleBot3）
- **实时数据**: 20Hz 更新频率
- **相机控制**: 
  - 左键拖动：旋转视角
  - 右键拖动：平移
  - 滚轮：缩放

## 依赖项

- Python 3.8+
- websockets >= 12.0
- aiohttp >= 3.9.0（可选，用于更好的 HTTP 服务）

## 故障排除

### WebSocket 连接失败

1. 确保 websockets 已安装：
   ```bash
   pip3 install websockets
   ```

2. 检查端口是否被占用：
   ```bash
   # Windows
   netstat -ano | findstr :8080
   netstat -ano | findstr :8081
   
   # Linux
   lsof -i :8080
   lsof -i :8081
   ```

3. 使用其他端口：
   ```bash
   python server.py 9000
   ```

### 页面无法加载

1. 确认服务器正在运行
2. 检查防火墙设置
3. 尝试清除浏览器缓存

## 与 ROS2 集成

如果在 WSL2 中运行且已安装 ROS2：

```bash
# 在 WSL2 中启动
source /opt/ros/humble/setup.bash
cd v2x_traffic_sim/smart_car_gui/web_3d
python3 server.py
```

服务器会自动订阅 `/model_states` 话题并显示真实仿真数据。

## 模拟模式

如果没有 ROS2，服务器会自动使用模拟数据：
- 5 辆小车在场地中移动
- 模拟 LiDAR 扫描数据
- 演示所有可视化功能
