## 使用方法

### Windows 用户（推荐）

1. **双击运行** `start.bat`
   - 自动安装依赖
   - 默认端口 8080
   - 浏览器会自动打开

2. **命令行运行**：
   ```cmd
   cd v2x_traffic_sim\smart_car_gui\web_3d
   python server.py
   ```

3. **自定义端口**：
   ```cmd
   python server.py 9000
   ```

### WSL/Linux 用户

```bash
cd v2x_traffic_sim/smart_car_gui/web_3d

# 首次运行需要安装依赖
pip3 install -r requirements.txt

# 启动服务器
python3 server.py
```

## 故障排除

### 端口被占用
```bash
# 查看占用情况
netstat -ano | findstr :8080
netstat -ano | findstr :8081

# 使用其他端口
python server.py 9000
```

### 依赖未安装
```bash
pip install websockets aiohttp
```

### WebSocket 连接失败
1. 确保服务器正在运行
2. 检查防火墙设置
3. 查看浏览器控制台错误信息
4. 尝试清除浏览器缓存
